    What people use it for

    Reply with the moment

    Turn the three seconds that matter into a GIF and drop it in Slack, Discord or a GitHub issue.

    Repost a stream highlight

    Grab a Twitch clip as a 9:16 video, ready to post to Reels, Shorts or TikTok.

    Send it without a size error

    “Small” squeezes the clip under 10 MB, so Discord and WhatsApp take it as is.

    Keep the audio

    Save a quote, a song snippet or a podcast moment from a post as an MP3.

    Why not screen-record it? Recording is real time, captures the player's buttons and drops quality. ClipGrab cuts the original file, so a 10-second clip takes a few seconds and looks exactly like the source.

    How it works

    1. Look up. The server checks the link and asks yt-dlp what's there, without downloading. You get a preview to scrub through.
    2. Cut. Only the part you picked is downloaded, and ffmpeg trims it.
    3. Convert. For GIF, MP3, Small or 9:16, one ffmpeg command turns the clip into that format.
    4. Send. The file streams to your browser and is deleted from the server straight away.
